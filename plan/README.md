# Clash Verge Rev 功能盘点

本文档记录当前产品能力边界，用于后续新增 `vergectl` 命令或 agent skill 时对照，避免为了 CLI 重造 UI 已有流程。

## 首页状态

- 当前配置、当前代理、代理模式。
- 流量、内存、连接、规则命中。
- 代理延迟检测和基础运行状态。

## 代理与配置

- 代理组和节点选择。
- 节点测速、provider 健康检查。
- Profiles 导入、更新、删除、重排。
- 本地配置编辑。
- Merge 和 Script 增强。

## 运行观察

- 连接列表和连接详情。
- 规则列表。
- 核心日志、日志过滤。
- 流媒体解锁测试。

## 系统能力

- 系统代理、PAC、绕过规则。
- 代理守卫。
- TUN。
- 开机自启、静默启动。
- 网络接口。
- UWP 工具。

## 设置与维护

- Clash 端口、DNS、外部控制器、Web UI、核心切换。
- Verge 外观、热键、轻量模式、诊断。
- 本地备份和 WebDAV 备份。
- service 和 sidecar 核心管理。
- `vergectl` 安装、卸载和 agent skill 安装。
