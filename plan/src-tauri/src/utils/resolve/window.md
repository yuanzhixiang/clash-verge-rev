# 主窗口创建与原生表面

## 模块职责

模块根据用户主题模式创建主窗口、设置启动背景、恢复合法窗口尺寸，并负责 macOS 原生标题栏的初始材质。

## 窗口行为

- 主窗口默认尺寸为 940×700，最小尺寸为 520×520，过小的历史窗口尺寸恢复为默认值。
- Windows 与 macOS 使用系统窗口装饰；Linux 沿用无边框窗口。
- macOS 标题栏使用 Tauri `Overlay` 样式，保留系统标题和红黄绿按钮，让 WebView 的壳层画布绘制到标题栏下方。
- 前端必须提供 28px 安全拖拽区，正文内容不得进入标题或交通灯区域。

## 主题与启动背景

- Light 窗口背景为 `#edf2f7`，Dark 窗口背景为 `#151619`，必须与前端壳层画布色一致。
- 显式 Light/Dark 模式直接使用对应颜色；System 模式在窗口创建前根据系统外观选择。
- 初始化脚本接收相同色值，在 React 和主题数据就绪前先绘制一致背景，避免闪白或标题栏断色。
- 运行中的主题变化由前端窗口 API 同步；创建逻辑负责首次显示前的正确颜色。

## 错误与兼容

- 设置原生窗口背景失败时记录错误，但不阻止窗口创建、显示或聚焦。
- Overlay 标题栏只在 macOS 编译目标启用，不改变 Windows 与 Linux 的装饰和布局。
