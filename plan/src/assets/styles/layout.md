# 应用壳层布局样式

## 模块职责

样式模块负责应用壳层、展开与紧凑侧栏、主内容面板、平台标题栏适配和窄窗口响应式布局。

## macOS Overlay 安全区

- macOS 使用原生 Overlay 标题栏时，在壳层最顶部渲染固定 28px 高的安全区。
- 安全区使用 `--shell-canvas` 作为背景，并标记为 Tauri 拖拽区域，使标题栏与应用画布成为连续表面。
- 安全区不承载按钮或正文；原生标题、红黄绿窗口按钮继续由 macOS 绘制在其上方。
- 安全区占用正常 flex 布局高度，侧栏品牌、导航和主内容面板均从其下方开始，不得通过绝对定位产生遮挡。
- 系统装饰关闭时不渲染该安全区，避免与已有自绘标题栏重复占位。

## 平台与响应式边界

- Windows 原生标题栏和 Linux 自绘标题栏尺寸不受 macOS 安全区影响。
- 侧栏展开、折叠及 720px 以下自动紧凑行为保持不变。
- 安全区只改变 macOS 可用内容高度，不改变主面板水平间距、圆角或滚动结构。
