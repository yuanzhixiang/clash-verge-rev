# 应用壳层布局样式

## 模块职责

样式模块负责应用壳层、展开与紧凑侧栏、主内容面板、平台标题栏适配和窄窗口响应式布局。侧栏只承载导航，不为已移除的品牌区和流量区保留空容器。

## macOS Overlay 安全区

- macOS 使用原生 Overlay 标题栏时，不再渲染横跨整个壳层的顶部占位；`.layout-content` 占满窗口高度。
- 展开侧栏内部先渲染固定 28px 高的交通灯安全区，导航在其下方以独立顶部留白开始；右侧主面板保持 12px 顶部外间距，因此其圆角表面进入原生标题栏区域。
- 主面板内部先渲染固定 28px 高的空白拖拽带，路由页面在独立内容 body 中使用剩余高度；拖拽带不得承载页面按钮或正文。
- 左栏安全区使用 `--shell-canvas`，面板拖拽带使用 `--shell-panel`，两者均标记为 Tauri 拖拽区域；`html`、`body`、`#root` 和壳层继续使用不透明的 `--shell-canvas`。
- 系统装饰关闭时不渲染左栏安全区和面板拖拽带，避免与已有自绘标题栏重复占位。
- macOS 侧栏使用与画布相同的不透明表面并禁用背景模糊，避免交通灯区域与其正下方因不同合成层产生横向断色；Windows 与 Linux 保持原有侧栏材质。
- 标题栏与正文交界处不增加边框、渐变或阴影。macOS 主内容面板保留 12px 外间距、16px 圆角、hairline 边框和独立表面色，但关闭外阴影；Windows 与 Linux 保持原有阴影。

## 平台与响应式边界

- 展开侧栏导航占据安全区之外的可用高度，菜单项采用紧凑纵向节奏；侧栏顶部和底部不渲染品牌、更新按钮、流量图、实时速度或内存卡片。
- 侧栏展开时使用进入标题栏的主面板；用户折叠侧栏或窗口宽度不超过 720px 时，主面板顶部间距增加 28px 并隐藏内部拖拽带，使面板退回标题栏下方。
- 页面、日志覆盖层和虚拟列表都挂载在主面板内容 body 中；安全区不得破坏 `height: 100%`、滚动容器或绝对定位的高度基准。
- Windows 原生标题栏和 Linux 自绘标题栏尺寸不受 macOS 安全区影响。
