# 基础页面容器

## 组件职责

`BasePage` 为常规路由提供统一的页面标题、头部操作区和可滚动内容区，是 Surge 式桌面信息层级在各业务页面的公共入口。

## 视觉与排版

- 宽屏页头高 76px，左右留白 28px；标题使用 28px、650 字重和轻微负字距，形成明确但克制的页面锚点。
- 内容区与页头使用同一主面板表面，二者只以 hairline 分隔，不再混用独立灰色页面背景。
- 常规内容左右保留 28px，最大宽度 1440px；页面自身仍可通过 `full` 进入无内边距模式。
- 窄窗口页头收紧为 66px，标题 24px，水平留白改为 18px。

## 交互与组合关系

- `title` 只承载页面名称，`header` 承载搜索、筛选和图标操作；两者保持单行主次关系。
- 内容滚动、错误边界和 `full` 模式沿用既有行为，不改变页面业务状态。
- 颜色仅使用 shell 变量，兼容 Light、Dark 和用户自定义主色。

## 可访问性

- 页头继续作为 Tauri 拖拽区域，但其中的交互控件保持可点击。
- 标题与正文对比度不能依赖用户强调色；键盘焦点由全局主题提供可见焦点环。
