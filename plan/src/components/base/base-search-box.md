# 基础搜索框

## 组件职责

基础搜索框统一提供文本筛选、大小写匹配、整词匹配、正则匹配和输入清空能力，并把编译后的匹配函数返回给业务页面。

## 使用场景

- 规则、连接、日志等需要客户端筛选的页面。
- 规则页可传入前置搜索图标和局部 `sx`，呈现 Surge 式工具栏搜索框。

## Props 与数据输入

- 保留文本值、默认值、自动聚焦、占位符、三种匹配选项和 `onSearch`。
- 新增可选 `startAdornment`，用于业务页面提供前置图标。
- 新增可选 `sx`，只作用于搜索框根节点；缺省时不改变现有页面样式。

## 视觉状态

- 默认沿用 MUI 主题和现有页面外观。
- 业务页面可通过 `sx` 调整圆角、表面和尺寸。
- 激活的匹配选项使用主题主色，未激活项使用中性色。

## 交互状态

- 输入变化立即编译并发出新的匹配函数。
- 清空、大小写、整词和正则切换立即更新搜索状态。
- 无效正则显示错误状态和本地化提示。

## 键盘、Hover、Focus、Disabled 与 Loading

- 输入框和图标按钮可通过键盘操作，并显示可见焦点状态。
- 图标按钮继续提供本地化 Tooltip。
- 组件没有独立 loading 状态。

## 边界状态

- 受控和非受控值继续兼容。
- 相同搜索状态不得重复触发 `onSearch`。
- 未传 `startAdornment` 或 `sx` 时保持原行为。

## 组合关系

- 规则页使用前置搜索图标和局部样式，其它页面无需迁移。
