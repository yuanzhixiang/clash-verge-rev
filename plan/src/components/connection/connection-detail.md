# 连接详情抽屉

## 组件职责

`ConnectionDetail` 展示单条连接的排查详情，并提供关闭单条连接的操作。

## 交互状态

- 由连接页通过 ref 打开、切换和关闭。
- 打开后固定在 Connections 内容区底部，展示为底部抽屉，不使用全屏遮罩。
- 已打开时点击其它连接行，抽屉内容直接替换为新连接。
- 已关闭连接只展示信息，不显示关闭连接按钮。

## 信息架构

- 顶部展示主机、Live/Closed 状态、开始时间、连接类型、关闭连接按钮和收起按钮。
- Route 区展示 App、Inbound、Rule、Policy、Exit、Remote 调用链路。
- Details 区使用两列字段展示源地址、流量、速度、目标、进程、时间、端口和链路文本。

## UI/UX 约束

- 使用 MUI 和当前主题色，不新增全局样式或设计依赖。
- 抽屉最大高度限制在视口下半区，内部可滚动。
- 长域名、进程路径和节点名称必须截断或换行，不允许撑破抽屉。
