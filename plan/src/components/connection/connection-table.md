# 连接表格

## 组件职责

`ConnectionTable` 负责 Connections 表格视图的虚拟滚动、列管理、排序和行点击详情入口。

## 交互状态

- 行点击由页面传入 `onShowDetail` 处理。
- 当前打开详情的连接通过 `selectedId` 高亮，使用淡紫背景，不改变数据排序和缓存逻辑。
- 表格继续保留列宽拖拽、显示隐藏、排序和虚拟滚动能力。

## UI/UX 约束

- 选中态只改变当前行背景，避免影响虚拟滚动高度。
- 链路列使用 `ConnectionRouteChips` 展示紧凑 route badge。
- 表头必须单行显示；空间不足时使用省略号，不允许换行或覆盖相邻列。
