# 导航项组件

## 组件职责

导航项组件渲染单个固定全局路由入口，负责当前路由选中态、页面预加载和折叠态提示。

## 使用场景

- 应用侧栏普通导航模式。
- 用户主动折叠或小窗口自动紧凑显示模式。

## Props 与数据输入

- `to`：目标路由。
- `children`：本地化后的导航标签。
- `icon`：单色 MUI 图标和可选彩色 SVG 图标。
- `onPreload`：hover、focus 或 pointer down 时调用的页面预加载函数。

## 视觉状态

- 默认态使用常规字重文字和低饱和中性图标。
- hover 态提升侧栏表面亮度，不使用强饱和背景。
- 按下态使用比 hover 更明确的中性表面反馈。
- 选中态只增加柔和中性底色，文字字重、文字颜色和图标颜色与默认态保持一致。

## 交互状态

- 点击导航到目标路由。
- hover、focus 和 pointer down 触发预加载。
- `focus-visible` 显示主题主色焦点环。

## 边界状态

- 折叠态隐藏文字并使用 `title`、`aria-label` 暴露标签。
- 彩色图标被禁用时回退到单色图标。
- 预加载失败被吞掉，不影响导航点击。

## 组合关系

- 由应用布局的固定导航列表复用；Proxies 分组标题由布局单独渲染。
- 视觉尺寸与布局的 220px 展开侧栏、72px 折叠侧栏保持一致。
