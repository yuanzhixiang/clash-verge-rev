# 导航项组件

## 组件职责

导航项组件渲染单个全局路由入口，负责当前路由选中态、页面预加载、折叠态提示和可选拖拽排序能力。

## 使用场景

- 应用侧栏普通导航模式。
- 菜单解锁后的拖拽排序模式。
- 用户主动折叠或小窗口自动紧凑显示模式。

## Props 与数据输入

- `to`：目标路由。
- `children`：本地化后的导航标签。
- `icon`：单色 MUI 图标和可选彩色 SVG 图标。
- `sortable`：拖拽引用、监听器、样式和拖拽状态。
- `onPreload`：hover、focus 或 pointer down 时调用的页面预加载函数。

## 视觉状态

- 默认态使用中性文字和图标。
- hover 态提升侧栏表面亮度，不使用强饱和背景。
- 选中态使用中性选中底色、较高字重和清晰前景色。
- 拖拽态降低透明度并提高层级。

## 交互状态

- 点击导航到目标路由。
- hover、focus 和 pointer down 触发预加载。
- 拖拽开启时显示抓取光标，按既有 DnD 键盘策略工作。
- `focus-visible` 显示主题主色焦点环；disabled 状态不得响应拖拽。

## 边界状态

- 折叠态隐藏文字并使用 `title`、`aria-label` 暴露标签。
- 彩色图标被禁用时回退到单色图标。
- 预加载失败被吞掉，不影响导航点击。

## 组合关系

- 由应用布局在普通列表和 `SortableContext` 中复用。
- 视觉尺寸与布局的 220px 展开侧栏、72px 折叠侧栏保持一致。
