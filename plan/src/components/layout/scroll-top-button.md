# 返回顶部按钮

## 组件职责

组件在长列表离开顶部后显示浮动返回入口，并通过平滑滚动回到列表起点。

## 使用场景

- 规则虚拟列表。
- 测试页和代理组链等既有长列表。

## Props 与数据输入

- `show`：控制淡入、淡出与可见性。
- `onClick`：执行所属列表的返回顶部动作。
- `ariaLabel`：可选的本地化可访问名称；页面应在可用时传入。
- `sx`：调用方局部样式覆盖入口。

## 视觉与交互状态

- 隐藏态不参与可见交互，显示态保留既有淡入动画。
- hover 使用轻量表面提升，`focus-visible` 由调用页面按主题补充。
- 按钮支持鼠标和键盘触发；图标不能作为唯一可访问名称。

## 边界与组合关系

- 组件不持有滚动容器引用，由调用方决定滚动目标和动画。
- 未传 `ariaLabel` 时保持既有调用兼容；新增或重做页面必须传入明确名称。
