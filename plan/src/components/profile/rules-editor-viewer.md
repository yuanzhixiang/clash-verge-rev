# Profile 规则增强编辑器

## 组件职责

规则增强编辑器维护 prepend、append、delete，并在可视化编辑时无损保留规则页生成的 replace 原位替换条目。

## 数据与兼容

- 打开时读取 `replace: [{ from, to }]`；可视化模式不展示或修改 replacement，但序列化时必须原样写回。
- 高级 YAML 模式允许用户查看和修改 replace；返回可视化模式后继续保留合法条目。
- 旧文件缺少 replace 时按空数组处理，不影响现有新增、删除和拖拽逻辑。

## 保存与边界

- 保存继续使用现有 Profile 文件校验和运行时重载链路。
- replace 结构非法时不静默丢弃，由保存或规则配置校验提示错误。
