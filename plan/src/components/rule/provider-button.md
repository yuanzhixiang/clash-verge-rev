# 规则集合入口与弹窗

## 组件职责

组件负责在存在规则集合时展示入口，并提供查看、更新单个集合和更新全部集合的弹窗。

## 使用场景

- 规则页顶部工具栏。

## Props 与数据输入

- 组件无外部 props，从规则数据上下文读取 `ruleProviders`，从刷新器上下文读取刷新函数。

## 视觉状态

- 入口使用紧凑次要按钮，与搜索框并列。
- 弹窗采用与主面板一致的表面、hairline 边框和圆角。
- 集合行展示名称、规则数量、更新时间、载体类型和行为类型。
- Dialog 通过 Portal 渲染时必须在 Paper 上重新声明壳层主题变量，禁止透明表面。

## 交互状态

- 没有集合时不渲染入口。
- 更新单项时只禁用对应按钮并显示旋转状态。
- 更新全部时串行处理集合，单项失败不阻断后续集合。
- 成功、失败和无集合反馈沿用现有通知系统。

## 键盘、Hover、Focus、Disabled 与 Loading

- 入口、更新全部和单项更新按钮均可通过键盘访问。
- hover 只提升表面层级；`focus-visible` 使用主题主色焦点环。
- 更新中按钮使用 disabled 状态并保持可理解的加载反馈。

## 边界状态

- 集合名称和更新时间过长时截断，不挤压操作按钮。
- 关闭弹窗不取消已提交的更新任务。
- 列表内容独立滚动，标题和底部操作区固定；窄窗口下标题与全部更新按钮纵向排列。
- Paper 最大高度不得超过视口，light/dark 下背景、边框与阴影均必须有效。

## 组合关系

- 由规则页工具栏使用，更新完成后同步刷新规则和规则集合数据。
