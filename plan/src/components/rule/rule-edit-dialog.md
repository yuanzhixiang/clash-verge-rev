# 编辑规则弹窗

## 组件职责

编辑弹窗预填一条完整运行时规则，允许修改 Type、Value、Policy 和 no-resolve，并把序列化后的新规则交给规则页原位保存。

## 数据与状态

- 接收打开状态、提交状态、解析后的初始规则、运行时选项、现有规则和保存回调。
- 每次打开或目标变化时重置为目标规则；不显示 prepend/append 位置。
- 完全相同的提交作为无变化关闭；与其它运行时规则重复时阻止保存。

## 交互与可访问性

- 标题使用“编辑规则”，确认按钮复用“保存”；提交中锁定关闭和重复保存。
- 初始焦点落在 Rule Type；Escape 关闭，Autocomplete 键盘语义与新增弹窗一致。
- 保存失败保留弹窗内容并显示通知，成功后由规则页关闭弹窗并刷新。
