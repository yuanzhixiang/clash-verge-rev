# 规则行组件

## 组件职责

规则行组件把单条运行时规则渲染为虚拟化表格的一行，并承载单选删除目标的键盘和指针交互，以及行尾的启停开关。

## 使用场景

- 规则页六列表格的虚拟滚动数据行。

## Props 与数据输入

- `value`：包含 `index / type / payload / proxy / extra.hitCount / extra.disabled` 的 `RuntimeRule`。
- `displayIndex`：当前筛选结果中的显示序号，仅用于斑马纹，不替代规则 ID。
- `selected`：当前行是否为删除目标。
- `canToggle`：是否允许启停，由页面按活动 Profile 与规则增强文件可用性决定。
- `toggling`：当前行是否正在提交启停变更，用于锁定开关避免重复提交。
- `onSelect`：请求选择当前规则的回调。
- `onEdit`：请求编辑当前规则的回调。
- `onToggleEnabled`：请求把当前规则切换为启用或「保留但禁用」的回调，参数为目标启用状态。

## 视觉状态

- 行高固定 32px，六列与表头严格对齐。
- 数据行不使用逐行横线；奇偶行使用轻微表面差，hover、focus 和 selected 逐级提高对比度。
- Policy 可使用主题派生的克制文字色，但必须保留文本。
- 禁用行压暗五个信息列并对 Value 加删除线；开关列不压暗，否则禁用后更难点回来。
- 禁用不改变行的位置、ID 和高度，行始终留在原优先级槽位。

## 交互状态

- 点击行选择当前删除目标；再次点击不取消，避免减号目标不明确。
- 聚焦行按 Enter 或 Space 执行选择。
- 双击行或聚焦行按 F2 请求编辑；双击前产生的单选状态保留。
- 单元格文本允许选择和复制。
- 长文本截断并通过 `title` 展示完整值。
- 行尾开关表示「启用」：打开为参与匹配，关闭为保留在列表但不参与匹配。
- 开关列吞掉点击与双击事件，切换不改变当前选中行也不触发编辑。
- `canToggle` 为假或 `toggling` 为真时开关禁用，tooltip 说明不可用原因。

## 键盘、Hover 与 Focus

- 行进入 Tab 顺序并提供可见焦点环。
- 行使用 `aria-selected` 暴露选择状态，并用 `data-disabled` 暴露禁用状态供样式使用。
- 开关有本地化 `aria-label`，语义随当前状态在「启用这条规则」与「禁用但保留」之间切换。
- F2 不触发选择切换，并阻止浏览器默认行为。
- 表格语义由行和单元格的 ARIA role 提供。

## 边界状态

- 空 payload 显示 `-`。
- `hitCount` 为零时显示 `0`，只有 `extra` 或字段缺失时才显示 `—`。
- `extra.disabled` 缺失按启用处理，只有显式为 `true` 才算禁用。
- 极长域名、规则表达式和策略名不得撑破列宽。

## 组合关系

- 由规则页的 `VirtualList` 渲染。
- 列宽通过规则页共享的 CSS 变量或网格模板与表头保持同步。
- 选择状态由规则页管理，2 秒 Used 刷新不得导致选择丢失。
- 开关是受控组件，真值来自核心的 `extra.disabled`；组件不缓存本地启停状态，写入失败时靠页面轮询自动回弹。
