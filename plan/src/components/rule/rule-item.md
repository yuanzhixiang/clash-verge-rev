# 规则行组件

## 组件职责

规则行组件把单条运行时规则渲染为虚拟化表格的一行，并承载单选删除目标的键盘和指针交互。

## 使用场景

- 规则页五列表格的虚拟滚动数据行。

## Props 与数据输入

- `value`：包含 `index / type / payload / proxy / extra.hitCount` 的 `RuntimeRule`。
- `displayIndex`：当前筛选结果中的显示序号，仅用于斑马纹，不替代规则 ID。
- `selected`：当前行是否为删除目标。
- `onSelect`：请求选择当前规则的回调。

## 视觉状态

- 行高固定 32px，五列与表头严格对齐。
- 奇偶行使用轻微表面差，hover、focus 和 selected 逐级提高对比度。
- Policy 可使用主题派生的克制文字色，但必须保留文本。

## 交互状态

- 点击行选择当前删除目标；再次点击不取消，避免减号目标不明确。
- 聚焦行按 Enter 或 Space 执行选择。
- 单元格文本允许选择和复制。
- 长文本截断并通过 `title` 展示完整值。

## 键盘、Hover 与 Focus

- 行进入 Tab 顺序并提供可见焦点环。
- 行使用 `aria-selected` 暴露选择状态。
- 表格语义由行和单元格的 ARIA role 提供。

## 边界状态

- 空 payload 显示 `-`。
- `hitCount` 为零时显示 `0`，只有 `extra` 或字段缺失时才显示 `—`。
- 极长域名、规则表达式和策略名不得撑破列宽。

## 组合关系

- 由规则页的 `VirtualList` 渲染。
- 列宽通过规则页共享的 CSS 变量或网格模板与表头保持同步。
- 选择状态由规则页管理，2 秒 Used 刷新不得导致选择丢失。
