# 规则集合详情弹窗

## 组件职责

组件负责按需读取并只读展示单个规则集合的具体规则，提供本地搜索、虚拟滚动和不可用状态说明。

## 数据与接口

- 输入集合名称、集合元信息、当前会话缓存和打开状态。
- 通过 `getRuleProviderContent` 获取 `ready` 或 `unavailable` 结果，不直接读取文件或请求远端 URL。
- `ready` 内容在管理弹窗会话内缓存；组件不负责跨会话持久化。

## 视觉与交互

- 使用约 820px 的二级 Dialog，标题展示集合名称，副信息展示格式、行为和规则数量。
- 返回和关闭均回到原 Provider 管理弹窗；搜索框只过滤当前已加载内容。
- 规则以序号和原始字符串展示，使用等宽字体与虚拟列表承载上万条数据。
- 长规则单行省略并通过 `title` 查看完整内容；hover 提升行表面层级。

## 状态与边界

- 加载、空结果、读取错误、缓存缺失、无显式缓存路径和 MRS 不支持均有独立状态。
- 读取错误允许重试；不可用状态不自动联网下载或转换 MRS。
- 窄屏下弹窗使用视口宽度并保持内部列表无页面级横向溢出。

## 可访问性

- 返回、关闭、搜索和重试均提供可访问名称与键盘操作。
- 虚拟列表保持稳定序号，搜索结果仍显示规则在原集合中的位置。
