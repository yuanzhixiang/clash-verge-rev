# 前端入口与启动遮罩

## 模块职责

前端入口在 React、配置和 MUI 主题初始化完成前提供与应用主题一致的基础颜色和全屏启动遮罩，避免 WebView 首帧闪白。

## 启动颜色

- Light 默认背景为 `#edf2f7`，Dark 默认背景为 `#151619`，与应用壳层画布及 macOS 原生窗口背景一致。
- CSS 媒体查询负责无初始化脚本时的系统深色兜底；Tauri 初始化脚本可以根据用户显式主题覆盖 CSS 变量。
- 主题准备完成后启动遮罩淡出并移除，不拦截后续交互。

## 视觉约束

- 首帧、主题加载态和正式壳层之间不得出现白色或旧主题色闪烁。
- 启动遮罩只使用实色背景，不复制应用布局、品牌或加载动画。
