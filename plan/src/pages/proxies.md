# 策略页面

## 页面定位

策略页面用于切换 Rule、Global、Direct 出站模式，浏览和选择策略组与代理节点，并提供链式代理入口。

## 页面头部与模式切换

- 页头显示 34px 强页面标题；标题下方为出站模式与 Chain Proxy 工具区。
- Rule、Global、Direct 使用同一等宽 Pill 分段容器，当前模式使用主色实底与白色文字；分段器下方显示当前模式说明。
- 分段按钮之间不绘制内部竖线。hover、focus 和选中状态不得在按钮边缘产生强调色竖线或被裁切的焦点框。
- Chain Proxy 为独立 38px tonal 按钮；窄窗口下与分段器自然换行。

## 信息架构

- 三种出站模式下始终展示完整配置总览，切换模式不隐藏 Policy Group 与 Proxy；页面先展示 Policy Group，再展示 Proxy。
- Proxy 区仅展示不属于 Provider 的独立真实叶子节点，过滤 DIRECT、REJECT、PASS 等伪节点；Provider 节点通过策略组浮层访问。节点卡片只用于查看与测速，不直接改变策略组选择。
- Proxy 区右侧提供 Test All 与 Proxy Provider。两者使用同一组 36px 高的页面操作按钮，文字、图标和焦点状态垂直对齐；Test All 对去重后的真实节点测速，不改变代理选择。
- Policy Group 区以无边框、低饱和背景的紧凑摘要卡片展示组类型、名称和当前节点；类型与当前节点均使用灰色弱化文本，当前节点前不显示对勾。点击卡片打开锚定浮层。
- Policy Group 与 Proxy 网格均使用 `repeat(auto-fill, minmax(180px, 240px))`，卡片保持紧凑且不横向拉伸；两者均不受普通模式下 `proxy_layout_column` 配置影响。

## 策略组浮层

- 浮层宽约 420px、最大高约 520px，锚定触发卡片并支持点击外部或 Escape 关闭。
- 顶部工具栏保留搜索、组测速、默认/延迟/名称排序和基础/详细信息切换。
- 节点列表使用虚拟滚动，当前节点以勾选和低透明度主色表面标识；长名称截断并提供完整提示。
- Selector、URLTest、Fallback 允许选择节点；其它自动策略组可查看但保持只读。
- 节点选择继续使用现有选择队列、配置持久化、托盘同步和可选连接清理流程。

## 交互与状态

- 点击模式按钮沿用现有 Clash 模式切换逻辑；启用自动关闭连接时继续执行既有连接清理流程。
- Chain Proxy 保留现有开关、警告与本地持久化行为。
- 普通模式由独立 Policy Dashboard 渲染；既有 `ProxyGroups` 和链式构建器仅继续承载 Chain Proxy。
- 参考图中的编辑、复制、删除和新增能力不在本轮范围内，不显示无效菜单占位。
- Chain Proxy 的入口/出口顺序、重复节点校验、连接、断开与运行时写回不变，只统一表面、间距和交互状态。

## 加载、空态与错误态

- 核心数据尚未返回时使用现有加载态；无真实节点或无策略组时分别在对应区块显示局部空态，另一块仍可使用。
- 三种模式下不再使用 Direct 专属整页空态。
- 测速和选择错误继续使用既有通知与错误恢复，不在卡片内复制错误面板。

## 响应式与可访问性

- 窄窗口下模式工具区换行，卡片网格从多列自然降为单列，不隐藏模式切换、Provider 或 Chain Proxy。
- 每个模式仍为独立原生按钮，保留键盘操作和可访问名称；颜色不是模式名称的唯一表达方式。
- 策略组卡片与浮层节点均可通过键盘访问；不可选择节点显式使用 disabled/只读状态。
- Light、Dark 均使用 shell 表面、hairline 与主题主色，不写死单主题背景。
