# 壳层主题变量

## 模块职责

模块根据 MUI Palette 生成应用壳层使用的画布、侧栏、面板、边框、交互和阴影 CSS 变量。

## 使用场景

- Layout 根 Paper 应用完整壳层变量。
- 通过 MUI Portal 渲染的 Rule Provider 和新增规则 Dialog Paper 重新应用同一变量集合。
- macOS Overlay 标题栏的窗口背景与顶部安全区复用画布颜色常量，不能另写一套近似色。

## 主题与边界

- 画布颜色固定为 Light `#edf2f7`、Dark `#151619`，并导出按主题模式读取画布颜色的能力。
- 其它 light/dark 颜色保持现有口径，焦点色继续使用用户主题主色。
- 返回值只包含 CSS 自定义属性，不操作 document 全局样式，避免影响非壳层页面和第三方组件。
- 调用方可在同一 `sx` 中继续覆盖具体背景或阴影，但不得复制另一套硬编码主题值。
