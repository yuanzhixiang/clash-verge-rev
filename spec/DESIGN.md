# 全局设计规范说明

## 文档职责

根目录 `DESIGN.md` 是全仓前端视觉与交互规范的唯一产品口径。本文件记录其实现边界，具体页面和组件仍由 `spec/` 下对应源码镜像文档描述。

## 圆角系统

- 全仓采用 Compact `6px`、Control `9px`、Container `12px`、Overlay `18px`、Shell `20px` 和 Pill `999px` 六级语义圆角。
- 运行时代码统一引用 `--radius-*` CSS 变量；禁止在 MUI `sx`、Emotion、内联样式或 SCSS 中复制像素值。
- Circle `50%` 仅用于宽高相等的头像、状态点、圆形图标和加载器，不属于普通容器层级。
- `0` 仅用于连续列表等明确取消圆角的组合边缘。
- 窄窗口主内容面板从 Shell 降为 Container，其余组件不因断点随意更换圆角层级。

## 维护约束

- 新组件先按语义角色选择已有 token，不新增相邻数值或页面专属变量。
- MUI 组件默认值由全局主题维护；业务组件只在语义角色确实不同于默认值时覆盖。
- `pnpm radius:check` 用于阻止新的圆角字面量和 MUI 数字倍乘写法进入源码。
- 本规范不改变业务流程、权限、数据结构或组件公开接口。
