# 桌面主窗口权限

## 能力定位

桌面 capability 只向主窗口开放应用运行所需的 Tauri 插件与窗口命令。

## 窗口主题权限

- 主窗口可以调用 `setTheme`，用于显式主题及跟随系统主题。
- 主窗口可以调用 `setBackgroundColor`，仅用于让 macOS 透明原生标题栏与应用壳层画布色同步。
- 背景色权限不用于用户输入、远程内容或任意窗口，只作用于受 capability 限定的 `main` 窗口。

## 安全与平台边界

- 不扩大文件、网络、Shell 或进程权限。
- Windows 与 Linux 虽共享 capability，但标题栏背景同步逻辑受前端平台判断限制，不改变其窗口装饰行为。
