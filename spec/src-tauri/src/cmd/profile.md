# Profile 命令

## 功能定位

Profile 命令负责配置列表、导入、创建、更新、激活、排序、编辑文件以及文件打开/定位等能力。`reveal_profile_file` 仅用于在系统文件管理器中定位已由应用管理的 Profile 文件。

## `reveal_profile_file`

### 请求与响应

- 请求：`index: string`，值为普通 Profile UID，或固定的 `Merge`、`Script` 标识。
- 响应：成功返回空值；解析、存在性检查或系统命令失败时返回错误字符串。

### 核心流程

1. 从当前 Profiles 配置按 index 查找条目，不接受前端提供的路径。
2. 读取条目的实际 file 字段，并解析到应用配置目录下的文件。
3. 验证目标存在后构造平台操作：macOS `open -R`，Windows Explorer `/select,`，Linux/其它平台打开父目录。

### 安全约束与边界

- 不暴露任意路径参数，不进行文件写入，不改变 Profile 配置。
- 缺少 UID、缺少 file 或目标不存在时直接失败，不启动外部程序。
- 普通 Profile、Merge 和 Script 走相同的受限解析流程。
- 平台命令参数必须作为独立参数传递，不经过 shell 字符串拼接。

### 副作用与并发

- 唯一副作用是启动系统文件管理器；命令不要求幂等锁，可并发调用。
- 远程只读开发桥接不调用该生产命令，避免开发页面影响宿主桌面。
