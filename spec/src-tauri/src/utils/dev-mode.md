# Safe Dev 运行边界

## 模块职责

模块提供编译期 safe-dev 标识，供应用启动、命令注册、退出清理、窗口事件和 IPC 路径统一判断开发安全模式。

## 安全约束

- `safe-dev` 必须同时启用现有 `verge-dev`，但使用独立于普通开发模式的 `.safe-dev` 数据与日志命名空间。
- 安全模式只允许创建真实主窗口和维护开发窗口自身状态。
- 不允许初始化核心、特权服务、系统代理、TUN、DNS、启动脚本、托盘、全局热键、静默更新或自动备份。
- 不允许注册可修改配置、核心、服务或系统网络的应用 command handler。
- 退出、重启和信号清理不得重置系统代理、恢复 DNS 或停止任何核心。
- safe-dev 的窗口状态文件和 Tauri identifier 必须与正式应用及普通 `dev:unsafe` 隔离。

## 生产边界

- 非 safe-dev 构建始终返回普通运行模式，生产构建、`dev:unsafe` 和现有正式启动流程不改变。
- 判断只依赖 Cargo feature，不接受网页参数或运行时用户输入，避免前端关闭安全边界。
