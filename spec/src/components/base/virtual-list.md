# 虚拟列表

## 组件职责

虚拟列表负责在固定滚动容器内只渲染可见项目，并向调用方暴露滚动控制与滚动事件。

## 使用场景

- 规则、连接、日志和 Profile 可视化编辑器的大数据列表。

## Props 与数据输入

- `count / estimateSize / overscan / getItemKey / renderItem` 控制虚拟化数据。
- `style` 允许页面覆盖根滚动容器的轴向 overflow、尺寸和布局样式。
- `onScroll` 监听根滚动容器，`footer` 保留现有尾部空间能力。

## 视觉与交互状态

- 默认根容器使用 `overflow: auto`。
- 默认 overflow 必须先于调用方 `style` 合并，使 `overflowX`、`overflowY` 等局部覆盖生效。
- 组件不自行定义业务表面、滚动条颜色或选中状态。

## 键盘、Hover、Focus 与边界状态

- 键盘行为由渲染项目和浏览器滚动容器提供。
- 数量为零时不渲染项目，由页面负责空态。
- 估算尺寸必须与固定行高一致，避免大量滚动时错位。

## 组合关系

- 规则页禁用横向滚动，由外层表格容器统一承担横向访问。
- 其它现有调用方未覆盖 overflow 时保持原行为。
