# 连接路由展示组件

## 组件职责

`connection-route` 负责把 Clash/Mihomo 返回的 `chains` 和页面组装出的步骤展示成可读链路。

## 使用场景

- `ConnectionRouteChips` 用在连接表格 `链路` 列，展示紧凑的 `策略 -> 出口`。
- `ConnectionRouteTimeline` 用在连接详情，展示 `应用 -> 入口 -> 规则 -> 策略 -> 出口 -> 远端`。

## 数据口径

- `chains` 按现有 UI 口径反转后展示，作为用户可读的出站方向。
- 最后一个链路节点视为出口节点，前面的节点视为策略或中间选择链。
- 空链路不渲染 chip，避免制造不存在的路径信息。

## 视觉状态

- 表格链路 chip 使用淡紫背景、primary 文字和轻 hairline 边框，节点之间用箭头表达方向。
- 详情链路节点横向排列，使用同一 primary 轻强调；空间不足时横向滚动，不换行撑高抽屉。
- 长文本使用省略号，完整值通过浏览器 title 暴露。
