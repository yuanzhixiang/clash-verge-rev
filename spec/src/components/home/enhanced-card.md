# 首页增强卡片

## 组件职责

首页增强卡片统一承载配置概览、当前代理、网络接管、代理模式、流量与诊断信息。

## Props 与内容结构

- `title` 与 `icon` 构成卡片标题区，`action` 为可选右侧操作。
- `iconColor` 只控制图标的语义色，不染色整张卡片。
- `minHeight` 与 `noContentPadding` 保持既有布局能力。

## 视觉状态

- 卡片使用实色高层表面、12px 圆角、hairline 边框和极轻环境阴影；标题区与正文以细分隔线组织。
- 标题为 16px、600 字重，图标位于 36px 的低饱和色块中。
- 桌面 hover 仅上移 1px 并略微加强边框与阴影，不改变内容颜色；触屏设备不触发悬浮效果。

## 边界与组合关系

- 长标题单行截断并保留原生 `title` 提示。
- 卡片高度由所在 Grid 行决定，内容区可以继续承载自身的加载、空态和错误态。
- Light、Dark 均使用 shell 表面变量，禁止在组件内写死旧主题背景色。
