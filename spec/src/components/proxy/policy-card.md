# 策略卡片

## 组件职责与使用场景

- `PolicyGroupCard` 在 Policy 页面展示策略组类型、名称和当前节点，并作为打开策略组浮层的入口。
- `PolicyProxyCard` 展示独立真实节点及其延迟测试入口；节点卡片与策略组卡片使用统一的紧凑尺寸和表面语言，同时保持各自的信息层级。

## 数据输入与组合关系

- 策略组卡片接收策略组数据、浮层开启状态、只读状态和点击回调，由 Policy Dashboard 以紧凑网格排列。
- 节点卡片接收节点数据和测速文案；测速操作不能触发策略组浮层或改变策略选择。

## 视觉与交互状态

- 策略组卡片使用无边框、低饱和表面，宽度为 180–240px、高度约 92px；类型和当前节点显式使用浅灰色文字（Light 为主文字 32% 透明度，Dark 为 47%），避免继承按钮主文字色，名称保持主要文字层级。
- 当前节点前不显示对勾；只读自动组继续在类型后显示 `Auto` 辅助信息。
- Proxy 节点卡片同样使用无边框、180–240px 宽和约 92px 高的紧凑表面；节点类型使用与策略组类型一致的浅灰色，节点名称保持主要文字层级。
- Proxy 测速结果继续使用既有成功、超时与错误状态色，未测速入口保持次要文字色，不因视觉统一而丢失状态语义。
- hover 只轻微改变中性表面并上移 1px；浮层打开时使用中性选中表面，不使用主色描边或主色背景。
- 卡片保留原生按钮语义、可访问名称、键盘激活和 `focus-visible` 焦点环；长文本单行截断并通过 `title` 提供完整内容。
- Light 与 Dark 均使用 shell 主题变量；空名称或空当前节点显示既有占位，不改变点击行为。
