# 策略页面

## 页面定位

策略页面对齐 Surge Mac 版 Policy 页的交互体验：切换出站模式、浏览与选择策略组节点、管理（编辑/复制/删除/新增）当前 Local profile 中的节点与策略组，并提供链式代理入口。

## 页面头部与模式切换

- 页头显示 34px 强页面标题；标题下方为出站模式与 Chain Proxy 工具区。
- 出站模式为紧凑分段器：内容自适应宽度、左对齐，顺序与 Surge 一致为直连出站、全局代理、规则代理；每段带 18px 图标（直连 SettingsEthernet、全局 Public、规则 AltRoute），选中段主色实底胶囊、白色文字，未选中透明底。
- 分段按钮之间不绘制内部竖线。hover、focus 和选中状态不得在按钮边缘产生强调色竖线或被裁切的焦点框。
- 分段器下方显示当前模式说明；Chain Proxy 为独立 tonal 按钮，窄窗口下与分段器自然换行。
- 模式切换、模式说明和 Chain Proxy 工具区不吸顶，与下方内容共用页面主滚动容器并随内容自然滚出视口；页面标题仍保持固定页头。

## 信息架构

- 三种出站模式下始终展示完整配置总览，切换模式不隐藏任何区块；**页面先展示 Proxy，再展示 Policy Group**（与 Surge 一致）。
- 普通策略总览和 Chain Proxy 模式统一使用单一页面纵向滚动条，不在内容区内创建嵌套滚动容器；Chain 模式右侧代理链面板按自身内容高度随页面滚动。
- 区块标题为全大写小标签样式（12px、加宽字距、主题主色，不用 Surge 的品红/青双色）。
- Proxy 区仅展示"手写独立节点"：过滤 DIRECT、REJECT、PASS 等伪节点、provider 节点，以及名字以任一现有组名 + `" / "` 开头的节点（Surge policy-path 展开节点命名约定，仅通过组浮层访问）。外部节点订阅迁移为 provider 后该前缀规则自然不再命中，作为兜底保留。
- Proxy 区右侧提供 Test All 与 Proxy Provider，两者使用同一组 36px 页面操作按钮；Test All 对去重后的真实节点测速，不改变代理选择。
- Policy Group 区以无边框、低饱和背景的紧凑摘要卡片展示组类型、名称和当前节点；左键点击不执行操作，右键打开锚定的菜单式浮层。
- 两个网格均使用 `repeat(auto-fill, minmax(180px, 240px))`；当前 profile 为 Local 类型时网格末尾显示虚线 "+" 新增卡片。

## 代理节点卡片

- 整卡可点击：点击触发该节点延迟测试，底部常驻显示"点击测速"或延迟值/加载态（对齐 Surge 的 Tap to Test）。
- 右键弹出上下文菜单（anchorPosition 定位）：编辑节点…、创建副本、删除节点…（危险色，弹确认框）、分隔线、测试节点延迟。
- 仅 Local profile 显示编辑/副本/删除项；非 Local profile 菜单只保留测试节点延迟，不显示无效占位。

## 策略组菜单式浮层

- 宽约 300px、最大高约 560px 的菜单式浮层；右键在鼠标坐标处弹出（anchorPosition，菜单左上角即光标），键盘打开（Enter/空格/菜单键）时锚定触发卡片；点击外部或 Escape 关闭。外观按 macOS 原生 NSMenu 像素规格实现（对照 Surge Mac）：毛玻璃半透明底（backdrop-filter blur）、10px 圆角、hairline 边框、柔和大阴影，不使用 shell 主题变量。
- 结构从上到下：管理操作（编辑策略组…、创建副本、删除策略组…，仅 Local profile 显示）→ 分隔线 → 组内测速 Benchmark（测速中置 disabled）→ 分隔线 → 节点列表。所有条目无图标、统一普通文字色（删除项不再红色），文字左缘经对勾列对齐。
- 动作项与节点行共用统一行组件：行高 24px、13px 系统字体、左右缩进 5px 的圆角高亮条；hover/键盘焦点高亮固定 macOS 蓝 + 白字（不跟随应用主题色）。
- 节点列表使用虚拟滚动（行高 24px），当前节点仅左侧文字色对勾标识（无行底色、不加粗）；**点击节点即切换并关闭浮层**；节点行右侧只读显示测速结果（测速中 loading、已测出彩色毫秒值、未测过留空，高亮行内变白），不提供单点测速入口，测速只通过 Benchmark。列表隐藏滚动条，溢出时顶部/底部显示 ⌃/⌄ 滚动指示箭头。
- 不再提供搜索框、排序切换、基础/详细切换和标题栏关闭按钮；节点顺序即配置顺序。
- Selector、URLTest、Fallback 允许选择节点；其它自动策略组节点行 disabled 只读。
- 节点选择继续使用现有选择队列、配置持久化、托盘同步和可选连接清理流程。

## 编辑能力（仅 Local profile）

- 编辑/新建节点与策略组共用 Monaco YAML 片段弹窗；新建时提供最小模板（节点 name/type/server/port 骨架、组 select + DIRECT）。
- 写回层（src/services/profile-editor.ts）直接读写当前激活 profile 主文件的 `proxies` / `proxy-groups`：
  - 新增/编辑校验 name 非空且在节点+组命名空间内唯一；改名时同步改写所有组对该名字的引用。
  - 创建副本自动命名 `name copy`、`name copy 2`…
  - 删除节点/组时从所有组的引用中移除；若某组因此失去全部出口（无 proxies、无 use、无 include-all）则保存前拒绝并提示。
  - 删除策略组的确认文案提示"规则中的引用需自行处理"；规则引用失效会被后端校验拦截并自动回滚文件。
- 保存走 `save_profile_file` 链路：后端验证失败自动回滚并返回错误信息（前端以通知展示），验证通过自动重新增强并热重载内核。
- yaml.load → yaml.dump 往返不保留主文件注释与键顺序，属已知限制。
- 判断依据：`useProfiles()` 当前 profile `type === 'local'`；非 Local profile 隐藏所有编辑入口（"+" 卡片、菜单项、浮层操作区）。

## 外部节点订阅（Surge policy-path 对应能力）

- profile 中 `proxy-providers` 声明 `verge-format: surge` + `url`（可选 `interval`、`ua`）即成为外部节点列表订阅，组用 `use:` 引用；详见 spec/src-tauri/src/module/external_provider.md。
- 此类 provider 的节点自动不进 Proxy 区（provider 节点既有过滤），组浮层可见可选。

## 加载、空态与错误态

- 核心数据尚未返回时使用现有加载态；无真实节点或无策略组时在对应区块显示局部空态（Local profile 下改为显示 "+" 新增卡片），另一块仍可使用。
- 测速和选择错误继续使用既有通知与错误恢复；编辑错误通过通知展示具体原因（YAML 语法、重名、空组、后端校验信息）。

## 响应式与可访问性

- 窄窗口下模式工具区换行，卡片网格自然降列，不隐藏模式切换、Provider 或 Chain Proxy。
- 每个模式仍为独立原生按钮，保留键盘操作和可访问名称；颜色不是模式名称/选中状态的唯一表达方式（当前节点有对勾）。
- 卡片、"+" 卡片与浮层节点均可通过键盘访问；策略组卡片支持 Enter、空格、菜单键与 Shift+F10 打开浮层，节点列表支持上下方向键移动焦点；不可选择节点显式使用 disabled 状态。
- Light、Dark 均使用 shell 表面、hairline 与主题主色，不写死单主题背景。

## 历史方案

- 2026-07 之前：Policy Group 区在 Proxy 区之前；组浮层带搜索框、排序切换与基础/详细切换；编辑/复制/删除/新增能力明确不做。本轮对齐 Surge 后全部废弃。
